# V!BE CMD

Двопанельний файловий менеджер для Windows. Fluent-вікно, виділення як у Total Commander, Quick View, який показує файл, а не іконку.

![Панелі](docs/Foto.jpg)

Windows · Delphi / FireMonkey · щоденний інструмент, не скін поверх `TListView`.

## Навіщо

Total Commander досі найшвидший спосіб рухати файли. Провідник — оболонка, в якій живуть усі інші. V!BE CMD стоїть між ними: дві панелі, клавіатура першою, сучасна рамка, прев’ю без зависання UI.

Панелі малюються самі (`TPaintBox` + віртуальний список). Іконки й метадані не читаються в циклі відтворення.

## Інтерфейс

### Хром вікна

- Власний Fluent title bar: іконка, заголовок, швидкий пошук по центру, налаштування, згорнути / розгорнути / закрити.
- Тема: як у системі / світла / темна. Акцент Windows підхоплюється.
- Матеріал вікна: звичайний / акрил / Mica (Windows 11).
- Заокруглені кути через DWM.

### Макет

Зверху вниз:

1. **Title bar** — живий фільтр активної панелі (`Ctrl+F` / `Ctrl+E`), історія запитів.
2. **Dock** — велика смуга ярликів (теки, файли, exe). Приймає DnD, переставляння мишею, роздільники, власні підписи й картинки. Мертвий шлях (флешка / мережа зникла) — сіра іконка, можна зняти вручну. ЛКМ по теці на докові відкриває її в активній панелі.
3. **Drive bar** — диски й вільне місце; пам’ятає останній шлях на кожному томі.
4. **Дві панелі** з вкладками в стилі Chrome / Explorer (`+`, закриття, перетягування).
5. **Середня колонка команд** — копіювати, перемістити, видалити, архів, нова тека, QV.
6. **Рядок стану** — об’єкт під курсором, розмір виділення, диск.

Кожна панель незалежна: шлях, вигляд, зум, сортування, курсор зберігаються на вкладку й пишуться в ini.

### Файлова панель

Два вигляди на одному компоненті:

| Вигляд | Поведінка |
| --- | --- |
| **Докладно** | Іконка + ім’я без розширення ліворуч; тип / розмір / дата праворуч. Коли панель вужчає, дата стискається (`дд.мм.рррр гг:хх` → `дд.мм.рр гг:хх` → `дд.мм.рр`), далі мета переходить на другий рядок, заголовки центруються як у плитках. Колонка імені гумова. |
| **Плитки** | Ескіз (`GetFileThumbnail` / кеш) + підпис. Для зображень на плитці — розмір (`1200×1600`), для медіа — тривалість. |

Спільне:

- `..` завжди першим рядком, якщо є батьківська тека.
- Приховані й системні — напівпрозора іконка (якщо увімкнено в налаштуваннях).
- Живий зум окремо для докладно й для плиток.
- Breadcrumbs + правка шляху на місці.
- Історія назад / уперед (`Alt+←` / `Alt+→`, кнопки миші).
- Фільтр із title bar застосовується до активної панелі одразу.
- Owner-draw + пул видимих рядків: на екрані десятки елементів, не десять тисяч контролів.
- Мережеві UNC (`\\host\share\…`) вантажаться у фоні шматками. Після обриву список не скидається на нуль; у рядку `..` — статус «підключення / сервер не відповідає» й дія «пропустити».
- Архіви відкриваються як теки (ZIP / TAR / GZ / 7z / RAR за наявності 7-Zip).

## Можливості

### Виділення (правила Total Commander)

Курсор і мультивиділення розділені. Фокус не стрибає після `Insert`.

- `Insert` / `Space` — перемкнути й зробити крок
- `Shift` — діапазон, `Ctrl` — точково
- `+` / `-` — маска (`*.pas;*.inc`)
- `Alt++` / `Alt+-` — той самий тип, що в курсора
- `*` — інвертувати
- `Ctrl+A` / `Ctrl+-` — усе / зняти
- Порівняти каталоги панелей

### Dock

- Піни: тека, файл, програма, роздільник
- Drop на теку дока → копіювання в неї
- Drop на exe → відкрити цими файлами
- Власні іконки: спочатку з exe / `.ico` / `desktop.ini` теки, без рамки, великі. Пункт меню «Змінити картинку» (растр; SVG якщо є Skia)
- Tooltip із підписом і повним шляхом
- Вирівнювання: ліворуч / центр / вільно
- Стан пишеться в ini без блокування UI

### Пошук (`F4` / `Alt+F7`)

Fluent-вікно в стилі налаштувань, не системний `TEdit`.

- Маска `*` `?` `;`
- Рекурсія, діапазон дати зміни
- Текст усередині файла (UTF-8 / ANSI)
- Список результатів owner-draw
- «Перейти» — активна панель на файл
- «Файли на панель» — віртуальний список хітів
- «У фоні» — вікно ховається, пошук іде далі

### Перейменування

- `F2` / `F9` — inline одне ім’я
- Кілька виділених → пакетне вікно: маски `[N]`, `[C]`, дати, знайти/замінити, колізії видно до застосування

### Буфер і DnD

- `Ctrl+C` / `X` / `V` — файли як у Провіднику
- `Ctrl+V` над панеллю, якщо в буфері зображення / PrintScreen — створити файл зображення в поточній теці й одразу прев’ю для плитки
- Drag між панелями, у Explorer, з браузера (URL / картинка качається у фоні)
- Вихідний drag через `SHDoDragDrop`

### Архіви

Віртуальна ФС всередині архіву. Запис: ZIP, TAR, GZ, TGZ, 7z. RAR — читання за наявності 7-Zip. `Alt+F5` пакує виділене в архів на іншу панель.

### Кошик

Видалення через Shell `FOF_ALLOWUNDO`, якщо режим це дозволяє. `Shift+Del` / налаштування «назавжди» — без Кошика.

## Quick View

Два місця: колонка всередині вікна (`Ctrl+Q`) і окреме вікно (`F3`). Зміна файла в панелі скидає незбережені правки зображення тостом, не модалкою.

| Родина | Що видно |
| --- | --- |
| Растр | JPEG / PNG / BMP / GIF / TIFF / WebP / TGA / ICO / CUR / HEIC / AVIF / JXL (якщо є WIC/Skia) |
| Вектор | SVG / SVGZ — Skia, зум векторний |
| PDF / AI | PDFium, сторінки, зум |
| PSD / PSB | вбудований прев’ю-ресурс |
| Таблиці | власна сітка xlsx / xlsm / xlsb / xls / csv / tsv — ліміти пам’яті, без падіння на кривих книгах |
| Документи | DOCX / ODT / RTF / Markdown сторінками-аркушами |
| Текст і код | два режими: аркуші A4 і моноширинний код (Cascadia / Consolas), підсвітка JSON / XML / MD / Pas / JS, виділення й копіювання |
| HTML | WebView2 (Edge), сторінка як у браузері; вихідник — текстовий режим |
| Шрифти | карта гліфів |
| Архіви | лістинг |
| Медіа | MFPlay (відео в дочірньому HWND зі збереженням пропорцій). Аудіо без вікна. Вирізка фрагмента: WAV lossless / Media Foundation / `ffmpeg.exe` поруч із програмою |
| Hex | дамп, якщо тип не вгадано |
| Тека | картка каталогу: іконка, шлях, розмір, лічильники |

Плитки використовують ті самі конвеєри через `uThumbCache` (RAM LRU + stamp за розміром/датою). Текст на плитці — міні-аркуш A4, як у DOCX.

### Мініредактор зображення (у QV)

Правки йдуть у буфер `FImgWork`. Файл на диску не чіпається, доки немає Save.

- Поворот 90° L/R, віддзеркалення H/V
- Розмір із lock пропорцій
- Кроп прямокутником (Enter / Esc)
- Save As: PNG / JPEG / BMP / WEBP, SVG→PDF, збірка ICO 16/32/48/256
- Стрічка кадрів ICO/CUR
- Якщо сигнатура не збігається з розширенням — банер «перейменувати»

## Файлові операції

Три режими в налаштуваннях:

| Режим | Поведінка |
| --- | --- |
| **V!be** (типово) | Власний рушій + плаваюче вікно прогресу: пауза, пропуск, фон, черга. Конфлікт імені в тому ж вікні: два прев’ю, «новіший», «для всіх». |
| **Тихий** | Без progress і без діалогів Shell. Пачка конфліктів — `uConflictDialog` із прев’ю. Спочатку йдуть файли без колізій, конфлікти — другим проходом. |
| **Провідник** | `SHFileOperation` з рідними вікнами Windows. |

Загальна логіка копіювання списків:

1. Звичайні файли йдуть одразу.
2. Колізія імені — в чергу конфліктів, пачку не зупиняє.
3. Після успіху виділення з джерела знімається.
4. DnD-копіювання показує лоадер на кнопці й знімає виділення в міру файлів.

Не можна перезаписати джерело самим собою. Офісні `~$lock` не копіюються як корисні об’єкти.

## Налаштування

Вікно картками, без VCL-контролів.

- Тема й матеріал вікна
- Показ дока / дисків / mid-bar / статусу / Fn
- Приховані й системні файли
- Шрифт списку (Segoe UI, 10–22)
- Іконки на вкладках, однакова ширина вкладок
- Кеш прев’ю: вкл/викл, ліміт 50–4000
- Режим файлових операцій
- Геометрія вікна й позиція спліттера

Файл: `VibeSetting.ini` поруч із exe. Старий `TCClone.ini` читається як одна вкладка на панель.

## Збирання

1. RAD Studio 12 або 13, платформа **Windows 32/64 — FireMonkey**.
2. Відкрий `.dpr` / project group.
3. Skia4Delphi — якщо в проєкті увімкнено `GlobalUseSkia` (SVG, частина прев’ю).
4. Збери Release. Налагоджувач на великих мережевих теках бреше про швидкість — міряти в Run without debugging.

## Залежності поруч із exe

Нічого з цього не обов’язкове, щоб панелі стартували.

| Файл | Навіщо |
| --- | --- |
| `pdfium.dll` | PDF / AI в QV і на плитках |
| Skia runtime | SVG, частина растру, анімації webp/gif/lottie |
| `ffmpeg.exe` | вирізка медіа в вихідному контейнері (gyan.dev essentials) |
| `7z.exe` / `7za.exe` | 7z / rar лістинг і пакування |

Без них відповідні формати деградують до іконки + info, програма не падає.

WebView2 Runtime потрібен для HTML-сторінки в QV. Якщо рушія немає — показується вихідник.

## Налаштування на диску

```
VibeSetting.ini     тема, панелі, вкладки, док, історія пошуку
```

Кеш прев’ю — в пам’яті процесу (LRU). На диск дамп таблиць не пишеться: прев’ю аркуша рахується знову, повна сітка — лише в QV.

## Статус

Робочий щоденний інструмент. Панелі, док, QV, пошук і операції використовуються постійно.

Відомі краї:

- Дуже великі UNC (тисячі фото) — фон + довантаження, не миттєвий повний лістинг як у локального SSD.
- Частина системних folder-thumbnails приходить від Shell із чорним/білим тлом — це поведінка Windows, не лише V!BE.
- Старий IE-fallback для HTML не цільовий; ціль — Edge WebView2.
